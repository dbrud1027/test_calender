# 주간 할 일 – 설정 안내

Claude 없이 쓰는 주간 할 일 페이지예요. 구성은 이렇게 나뉘어요.

| 맡는 일 | 어디서 | 파일 |
|---|---|---|
| 화면 | Vercel | `index.html` |
| 저장, 시트 가져오기 | 내 Google Apps Script | `apps-script/Code.gs`, `apps-script/appsscript.json` |

일정표 시트는 **읽기 전용 권한**으로만 열어요. 시트를 고치는 코드는 없어요.

준비물: 일정표 시트를 볼 수 있는 회사 Google 계정, GitHub 계정, Vercel 계정(GitHub로 가입하면 편해요)

---

## 1. Apps Script 만들기 (약 5분)

1. 회사 Google 계정으로 https://script.google.com 에 들어가 **새 프로젝트**를 만들어요. 이름은 '주간 할 일'처럼 알아보기 쉽게 지어 주세요.
2. 편집기의 `Code.gs` 내용을 모두 지우고, `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장해요.
3. 왼쪽 **⚙ 프로젝트 설정**에서 **"편집기에서 'appsscript.json' 매니페스트 파일 표시"**를 켜요. 편집기로 돌아와 `appsscript.json` 내용을 `apps-script/appsscript.json` 내용으로 바꾸고 저장해요.
   이 파일이 스프레드시트 권한을 읽기 전용으로 제한해요.
4. 위쪽 함수 목록에서 **setup**을 고르고 **실행**을 눌러요.
   - 권한 창이 뜨면 계정을 고르고 허용해 주세요. 권한 목록에 '스프레드시트 **보기**'만 있어야 정상이에요.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 돼요. 내가 만든 스크립트라서 나오는 안내예요.
5. 아래 **실행 로그**에 나온 `연결 키: ……` 값을 복사해 두세요. 나중에 키를 다시 보려면 `showKey`를 실행하면 돼요.

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형 옆 톱니에서 **웹 앱**을 골라요.
2. 설정은 이렇게 해 주세요.
   - **다음 사용자 인증 정보로 실행:** 나
   - **액세스 권한이 있는 사용자:** 모든 사용자
3. **배포**를 누르고, `https://script.google.com/…/exec`로 끝나는 **웹 앱 URL**을 복사해요.

> '모든 사용자'가 목록에 없다면 회사 Google 정책이 막아 둔 거예요. 이 방식을 쓸 수 없으니 알려 주세요.
>
> 웹 앱 주소와 연결 키를 둘 다 알아야만 데이터에 접근할 수 있어요. 키가 새어 나갔다면 `resetKey`를 실행하고, 각 기기에서 새 키로 다시 연결하면 돼요.

## 3. GitHub에 올리기

1. https://github.com/new 에서 저장소를 만들어요. 이름은 예를 들어 `weekly-planner`로 하고, **Private**을 권장해요.
2. 만든 저장소 화면에서 **uploading an existing file**을 눌러 `index.html`을 끌어다 놓고 **Commit changes**를 눌러요. README와 `apps-script` 폴더도 같이 올려 두면 나중에 고칠 때 편해요.

연결 키와 웹 앱 주소는 파일에 들어 있지 않아요. 저장소가 공개돼도 데이터는 안전해요.

## 4. Vercel에 배포하기

1. https://vercel.com 에 GitHub로 로그인한 뒤 **Add New… → Project**를 눌러요.
2. 방금 만든 저장소에서 **Import**를 눌러요.
3. Framework Preset은 **Other**로 두고, 나머지는 그대로 **Deploy**를 눌러요.
4. 끝나면 `프로젝트이름.vercel.app` 주소가 생겨요. 이 주소가 내 일정표예요.

## 5. 기기마다 처음 한 번 연결하기

페이지를 처음 열면 '저장 서버 연결' 창이 떠요. **웹 앱 주소**와 **연결 키**를 붙여 넣고 **연결하기**를 누르면 끝이에요.

휴대폰이나 다른 컴퓨터에서도 한 번씩 똑같이 해 주세요. 주소와 키를 나에게 메일이나 메모로 보내 두면 편해요. 연결 정보를 바꾸려면 페이지 맨 아래 **저장 서버 연결 설정**을 누르면 돼요.

## 동작 방식

- **시트 가져오기:** 시트는 10분마다 자동으로 가져와요. 페이지를 닫아 둬도 가져와요. 바로 가져오고 싶으면 페이지 위쪽의 **다시 가져오기**를 누르면 돼요.
- **기기 간 동기화:** 페이지는 1분마다, 그리고 다시 열 때마다 새 내용을 확인해요. 그래서 다른 기기에서 고친 내용도 금방 보여요.
- **탭 선택:** 오늘 날짜에 맞는 반기 탭(예: `2026_하반기`, `2027_상반기`)을 이름으로 찾아 읽어요. 새 탭이 시트의 어느 위치에 생겨도 괜찮아요.
- **가져오는 범위:** 이번 주부터 가져와요. 지난 주는 가져오지 않아요.
- **저장 공간:** 데이터는 이 Apps Script 프로젝트의 저장 공간에 보관돼요. 26주보다 오래된 주는 자동으로 정리돼요.
- **인터넷이 안 될 때:** 그 브라우저에 임시로 저장했다가, 다시 연결되면 자동으로 올려요.

## 고칠 때

- **Code.gs를 고쳤을 때:** **배포 → 배포 관리 → 연필 아이콘**을 누르고, 버전을 **새 버전**으로 골라 **배포**해요. 웹 앱 주소는 그대로예요.
- **index.html을 고쳤을 때:** GitHub에 다시 올리면 Vercel이 자동으로 다시 배포해요.
- **시트 구조나 이름 칸이 바뀌었을 때:** `Code.gs` 맨 위 `CONFIG` 부분을 고치면 돼요.
